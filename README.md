# Changelogs for Homey

Changelogs connects Homey app updates to your Flows. It monitors installed apps and retrieves release notes from the Homey App Store, letting you decide how to announce an update.

## What you can automate

- Start a Flow when an installed app updates, with its name, new version, previous version and changelog.
- React when an update becomes available for an app.
- Look up an installed app's latest changelog with an action card.

For example, connect the update trigger to a notification card to receive the release notes after an app changes version.

## Requirements

The app runs on local Homey version 12.4 or newer. It uses the Homey API to inspect installed apps and needs internet access to retrieve changelogs from the App Store.

## Source layout

`src/changelogService.ts` handles update monitoring and changelog retrieval. `src/flow/` contains the triggers, action and app autocomplete provider. The Vue settings interface is in `settings-ui/` and builds into `settings/`.

## Development

Use Bun for dependencies and scripts. Run these commands from the repository root:

```sh
bun install
bun run build
```

The root build also installs and builds the settings interface.

Edit Homey metadata in `.homeycompose/` and driver compose files where present. The root `app.json` is generated by Homey. `README.txt` and its translations contain the Homey App Store description; this Markdown file documents the GitHub project.
